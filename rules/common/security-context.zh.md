# 安全与上下文规则

## 禁止进入上下文的内容

不得读取、打印、摘要、提交或加入提示词：

- API 密钥、token、密码、私钥、证书、OAuth 材料。
- 真实 `.env` 文件或包含密钥的本地覆盖文件。
- 本地数据库、缓存目录、生成日志、崩溃转储、遥测导出。
- 浏览器配置、cookie 存储、shell 历史、个人账号数据。
- 构建产物，除非任务明确处理构建产物。

## 更安全的检查方式

优先使用只输出元数据的命令：

```bash
git status --short
git diff --name-only
rg --files
find . -maxdepth 2 -type f -name '*.md'
```

检查疑似敏感文件时只看文件名，不读内容：

```bash
rg --files -g '.env*' -g '*secret*' -g '*token*'
```

## 如果敏感内容出现

1. 停止展开该输出。
2. 不引用、不摘要敏感值。
3. 只说明遇到敏感内容，不复述内容。
4. 若任务确实需要，请人类提供脱敏版本。
